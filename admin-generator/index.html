How to Use This Generator

This generator creates a valid current-prices.json file for the public Live Lobster Price Board. It does not publish directly to the public website.

  1. Import the latest current-prices.json file, preferably downloaded from the Plesk server.
  2. Review and update page status, last updated time, announcements, contacts, prices, CNF add-ons, and disclaimer.
  3. Check the validation panel.
  4. Fix all validation errors before export.
  5. Review warnings carefully. Warnings do not block export.
  6. Export current-prices.json.
  7. Optionally export a timestamped backup for records.
  8. Replace local data/current-prices.json with the exported file and test the public page locally.
  9. Upload only current-prices.json to /data/current-prices.json on Plesk.
  10. Refresh the public website and verify the updated content.
Do not upload timestamped backup files to Plesk. The public website only reads: /data/current-prices.json
If the generator does not appear to update after changes, hard refresh the browser:
  • Mac: Command + Shift + R
  • Windows: Ctrl + Shift + R
